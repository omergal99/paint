# SKILL: TOKEN-EFFICIENCY PROTOCOL (CODEX EMULATION)

### 1. SURGICAL EDITS ONLY (DIFF-FIRST)
- NEVER rewrite or output entire files if modifying existing code.
- Apply strictly localized edits, precise line replacements, or targeted diffs.
- Do not add boilerplate comments or restate unchanged existing code.

### 2. TERSE EXECUTIVE OUTPUT
- Omit introductory chatter, greetings, summaries, explanations, and closing fluff.
- Output ONLY:
  1. Exact file path + code diff/modification.
  2. Executed terminal commands.
  3. Final status (PASS/FAIL).

### 3. DETERMINISTIC CLI VERIFICATION
- Read ONLY the specific functions or line ranges required. Do NOT dump large files or whole directories.
- DO NOT run interactive visual Playwright browser loops, UI screenshots, or DOM dumps unless explicitly authorized.
- Use ONLY deterministic, headless CLI checks when requested.

### 4. BATCHED EXECUTION
- Perform all file modifications in a SINGLE turn.
