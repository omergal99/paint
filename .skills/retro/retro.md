# Session retro

Use the loadable [maintenance skill](../../.agents/skills/maintenance/SKILL.md)
at session wrap-up. Keep the retro proportional to the work:

- outcome and evidence;
- friction, rework, or avoidable context/tool cost;
- relevant skills used or considered, without guessing missing history;
- one evidence-backed improvement, if any;
- unresolved user decision or risk.

Do not create a report, modify a skill, or run broad internet research merely
because a session ended. Follow the maintenance skill's bounded review and
20/50-session gates.
