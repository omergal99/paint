# Step 05 - Colors and Palette

## Goal

Make palette editing and transparency understandable and persistent.

## Tasks

- Replace ambiguous right-click behavior with a themed slot context menu.
- Migrate palette/foreground/background values to versioned RGBA state.
- Add primary/secondary alpha and transparent swatch affordances.
- Keep eyedropper, text, shapes, brush, eraser, and PNG output synchronized.

## Done when

Palette edits survive reload, context-menu actions are keyboard reachable, and
alpha values are honored by drawing and export.
