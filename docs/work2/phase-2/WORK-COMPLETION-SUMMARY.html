Paint 1.6.1 · local completion view · 20 September 2026

What changed?

The safety/build work is locally checked. Keyboard shortcuts are now user-configurable, persisted, and resolved from one constants-backed service. The remaining launch claims need a deployed HTTPS host and real devices.

Done locally

  • Pointer and editor teardown.
  • Autosave, quota, corrupt-record, and large-image recovery.
  • Production build + offline shell.
  • Startup restore is opt-in; first paint shows the default palette.
  • Localization registry + persisted Settings language selector; English and Spanish are ready, with future languages mapped safely.
  • 12/12 test files, TypeScript 7 check, build and release gates.

Settings improvements

  • Settings search scans hidden panels and highlights tabs/results.
  • History can start blank or restore the last image.
  • Session/history rerenders preserve position and pending captures settle first.
  • Press a new shortcut combination; conflicts are rejected and saved.

Still open

  • Public HTTPS install/update proof.
  • Desktop/mobile real-device matrix.
  • Mobile Lighthouse 90+ (local diagnostic is P76).
  • Reviewed non-English catalogs, RTL layout proof, and visible Step 12/13 UI workflows.

The same action names live in js/core/constants.js; behavior lives in js/settings/ShortcutManager.js.
