# Step 10 — Tests, Types, and Quality

## Goal

Make behavior—not source formatting—the durable regression contract.

## Tasks

- Add history, resize, palette, text, storage, EventBus, and DOM interaction tests.
- Keep shape-layer behavioral coverage and extend it for edge cases.
- Add `jsconfig.json`/`checkJs` and core typedefs.
- Add coverage reporting by subsystem.
- Remove or reduce brittle regex-only assertions as behavior tests land.

## Done when

CI is green, coverage is measured, and the highest-risk workflows have direct
behavioral tests.
